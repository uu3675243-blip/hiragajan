1 ゲームの基本と2つのモード

「ひらがじゃん」は、ひらがなの牌を使って単語を作り、揃えて上がる言葉探し麻雀ゲームです。

🃏 カード版（手軽・初心者向け）
  • 手札: 8枚（2文字語×1 ＋ 3文字語×2）
  • 山札: 4つの山から自由に選択して引く
  • 鳴き（ポン/カン/ロン）なし・手札オープン形式
🀄 パイ版（本格派）
  • 手牌: 14枚（2文字語×1 ＋ 3文字語×4）
  • 他人の捨て牌を利用する「ポン」が可能
  • 4文字語を作って晒す「カン」で山札補充

2 対局の詳しい操作手順

① 部屋の作成・参加

名前と任意の6桁部屋コードを入力し「作成」または「参加」を押します。

② モードを選ぶ

ヘッダーのセレクトで「カード版」か「パイ版」を選択（待機中なら全員の部屋に同期されます）。

③ 山札から牌を引く (ツモ)

自分の手番になったら、まず山札（カード版は4つの山）をタップして1枚引きます。引く前には捨てられません。

④ 不要な牌を捨てる (打牌)

手牌から牌をタップで選択し、「選択した牌を捨てる」を押します。捨てると手番終了です。

⑤ 鳴き・カン（パイ版のみ）

他人の捨て牌で3文字語を作れるなら「ポン」（手札2枚選択）。自分の手番で4文字以上の語が作れるなら「カン」（4枚以上選択、補充＝文字数−3）。

⑥ 上がり宣言 (ツモ/ロン) & 全員承認

完成した単語を空白区切りで入力欄に入力してから「ツモ上がり / ロン」を押します（相手の捨て牌直後ならロン）。宣言は全員の承認で確定します。

3 上がり判定（和了構造）の仕組み

🧩 手牌パーツの組み合わせ法則

麻雀の「雀頭1組 ＋ メンツ」と同様に、実在する日本語単語で手牌を隙間なく構成します。

・カード版 (8枚): 【2文字語 × 1】 ＋ 【3文字語 × 2】
・パイ版 (14枚): 【2文字語 × 1】 ＋ 【3文字語 × 4】

🚦 判定ゲート（宣言時に自動チェック）

  • 枚数ゲート: カード版は8枚・牌版は14枚でのみ宣言可（ロン時は捨て牌を含めてカウント）。
  • 構成ゲート: 入力した単語の文字数構成が【2＋3＋3】（カード版）／【2＋3×4】（牌版）／七対子【2×7】と一致すること。
  • 文字一致ゲート: 宣言した単語の文字集合と手牌（＋ロン牌）が完全に一致すること。
  • ロン条件: 相手の捨て牌直後のみ。自分が捨てた文字でのロン不可・鳴き経験者はロン不可（ツモのみ）。

🔤 文字・音の判定ルール

  • 清音（あ・い・う…）、濁音（が・ざ…）、半濁音（ぱ・ぴ…）は別々の文字として扱います。
  • 「ゃ」「ゅ」「ょ」「っ」「ー」などの拗音・促音・長音もそれぞれ1文字としてカウントされます。

🤝 全員承認による最終判定

単語の実在判定は自動辞書ではなく全員の承認で行います。上がり宣言時、入力された単語が全員の画面に表示され、プレイヤー全員が「承認する」を押すとFirebase上でアトミックに勝利・点数処理が確定します（牌版: ロン +3/−3、ツモ +3/各−1）。

🃏 カード版 — ルールブック

ひらがなのみで言葉を作る「言葉づくり麻雀」。麻雀の役や点数計算は不要で、手札は全員オープンです。公式案内の基本形に、オンライン対戦用の承認・操作ルールを加えています。

ルール
  • ひらがなの手札を並べ替えて実在する単語を作る
  • 手札は全員オープン（隠さない）
  • 役・点数計算はなし。鳴き（ポン/カン/ロン）もなし
操作方法
  1. 手番で山（4つのうちどれか）をタップして1枚引く
  2. 揃わなければ牌を選び「選択した牌を捨てる」
  3. 揃ったら単語を空白区切りで入力し「ツモ上がり」
勝利条件
  • 手札7枚＋引いた1枚＝8枚で【2＋3＋3】の3単語を完成
  • 最初に揃えた人の勝ち（1回勝負・点数なし）
  • 上がりはツモのみ。宣言は全員承認で確定
公式情報で確認できる基本ルール
  • プレイ人数は2人以上（推奨は2〜4人）。
  • 7枚を配り、自分の番に1枚引いて、合計8枚にします。
  • 2文字・3文字・3文字の3単語が揃えば勝ちです。
  • 手札はオープンで遊びます。固有名詞・造語・辞書の使用など、言葉の認定基準は開始前に全員で決めます。

① セット内容

ひらがなカード 計120枚:

  • 「を」を除く清音 全45音: 各2枚（合計90枚）

② セットアップ

  1. カードをよく混ぜる
  2. 各プレイヤーに7枚ずつ配る
  3. 残りは中央に4つの山に分けて置く（どの山から引いてもよい）
  4. 配られたカードは全員に見えるよう表向きに並べる
  5. じゃんけん等でスタートプレイヤーを決める
ルール
  • 手番で山札から1枚引き、手札7枚+引いた1枚=8枚で判定
  • 上がり形: 【2文字語×1 ＋ 3文字語×2】 = 3つの単語
  • 並べ替えはいつでも自由
  • 【2＋3＋3】が完成しない場合、手札から1枚を捨てる
  • 鳴き（ポン/カン/ロン）なし
  • リーチ・ツモ・チー等の発声なし

操作手順
  1. ヘッダーで「カード版」を選び、部屋を作成/参加
  2. 「対局開始」を押すと7枚ずつ配牌・時計回りに手番開始
  3. 手番:山(1〜4)をタップして1枚引く（ツモ）
  4. 完成できない時は牌をタップ選択→「選択した牌を捨てる」
  5. 完成したら入力欄に「ねこ いす とり」のように空白区切りで入力
  6. 「ツモ上がり」タップで宣言 → 全員承認で勝ち確定

④ 上がり判定の厳格ルール

宣言が通るには次の4つのゲートをすべて満たす必要があります（自動チェック）:

  • 枚数ゲート: 手札 ＋ 引いた1枚 ＝ ちょうど8枚（カード版で牌版14枚では宣言不可）
  • 構成ゲート: 入力した単語が【2文字×1】と【3文字×2】で構成
  • 文字一致ゲート: 入力した単語を結合した文字集合と手牌の文字集合が完全一致
  • 実在ゲート: 単語が実在の言葉。自動判定はないため他プレイヤーが全員承認して初めて成立

⑤ 文字の扱い

清音・濁音・半濁音はそれぞれ別物として数えます。「が」と「か」、「ぱ」と「は」は別々の牌扱い。

拗音（ゃ ゅ ょ）、促音（っ）、長音（ー）もそれぞれ1文字としてカウントされます（例: 「きょう」は4文字扱い）。

⑥ 戦略メモ

  • 3文字語を優先で作る（2文字より組み合わせが多いため）
  • 3文字語彙・2→3文字コンボを頭の中にストックしておく
  • 濁音・半濁音は作りにくい（麻雀の字牌ポジション）→ 先に切る
  • 狙った牌でなくても既存の並び替えで完成することがある

⑦ 難易度調整（推奨）

  • 小さな子: 揃える単語数を減らす（例: 2語で上がり）
  • 大人がチームを組んでサポートする
  • 単語認定範囲を事前に取り決める（固有名詞・略語の可否）
  • 変則ルール: 振り込み精算風、しばりルール（動物/食べ物/アニメ等）
  • 長考防止に制限時間（例: 10秒）
カード版ではポン/カン/ロン/七対子の各ボタンは表示されません。上がりはツモのみ。スコアの増減もありません。

🀄 パイ版 — ルールブック

カード版を牌にした本格バージョン。手牌を隠して遊べるため読み合いが生まれ、公式案内ではカード版にないポン・カン・ロンを追加しています。以下は公式に確認できる基本ルールと、このアプリで採用する拡張ルールを分けて表示しています。

ルール
  • 手牌を組み合わせて実在する単語を作る
  • 手牌は隠せる（読み合いが生まれる）
  • 役・ドラなし。ポン・カン・ロンあり（チーはなし）
操作方法
  1. 手番で山をタップして1枚引く
  2. 不要牌を選び「選択した牌を捨てる」
  3. 他人の捨て牌で3文字語が作れるなら手札2枚選択→「ポン」
  4. 4文字以上の語なら「カン」（文字数−3枚を補充）
  5. 揃ったら単語を空白区切りで入力し「ツモ上がり / ロン」
勝利条件
  • 手牌13個＋引いた1個＝14個で【2＋3×4】の5単語を完成
  • 得点: ロン +3／振込 −3、ツモ +3／他 各−1
  • 最初に揃えた人の勝ち。複数回の合計点で勝敗を決める
公式情報で確認できる基本ルール
  • 手牌は14個で、2文字語×1 ＋ 3文字語×4の5単語を目指します。
  • カード版と違い、手牌を隠して遊べるため、相手の狙いを読む駆け引きがあります。
  • カード版にはないポン・カン・ロンを使えます。
  • 初回は基本ルールだけで遊び、慣れてからポン・ロンを追加してもよいと公式FAQで案内されています。

③ 鳴きルール（ポン / カン / ロン）

ポン / ロン
  • 他プレイヤーの捨て牌で単語を作れる場合、「ポン」宣言で牌をもらえる
  • 上がりタイミングでのポンは「ロン」
  • ポンは捨てられた直後にのみ宣言可能
  • ポンで作った単語は手牌の右側に置き、全員に見せる
  • ポンしたら手牌を1枚捨て、左隣の手番になる
  • ポンしたらロン不可（ツモ上がりのみ）
  • 自分が捨てた牌と同じ文字をもらってのロンは不可
カン
  • 4文字以上の単語を作れたら「カン」できる（5文字以上でも可）
  • できた単語は手牌の右側に置き全員に見せる
  • カン後、作った単語の文字数 − 3枚を中央から補充
  • カンしたら1枚捨て、左隣の手番になる
数牌がないため「チー」はできない。1度でも鳴いたら以後はツモ上がりのみ（麻雀と同じ）。

④ 得点（点数計算）

ロン
  • ロンした人: +3点
  • 振り込んだ人: −3点
ツモ
  • ツモった人: +3点
  • それ以外の全員: 各 −1点

基本は上がれば3点。複数回プレイし合計点で勝敗決定。長考が出やすいためタイマー（例: 10秒〜）推奨。

⑤ 特殊役（ローカルルール）

七対子: 手牌のみで2文字×7単語を作れば上がり可能。ポン・カンをしている場合は不可。公式ルールではなく任意の追加役です。

役・ドラはなし（上がれば3点のシンプル設計）。

このアプリでは七対子を待ち画面で明示的にONにした場合にのみ採用されます。公式の基本ルールには含まれない、任意のローカルルールです。

⑥ ロン不可の厳格条件

ロン宣言が拒否されるケース（自動判定）:

  • 捨て牌直後以外（次の手番者が既にツモしている）
  • 自分が投げた文字でのロン（同じ牌を再利用できない）
  • 既に鳴き（ポン/カン）した人によるロン（ツモのみ可）

加えて、ポンやカン後は必ず1枚捨てるまで手番終了できません（捨て牌でphase=drawへ遷移）。

⑦ 戦略メモ

  • 使える文字（有効牌）は簡単に捨てない
  • 4文字以上の単語でカンして手牌を補充する発想
  • 相手の捨て牌・手牌を見て待ちを構える
  • 3文字語彙・2→3文字コンボをストック
  • 濁音・半濁音は作りにくいため先に切る

⑧ ハウスルール例（任意）

以下のルールは公式基本ルールではないため、任意の追加ルールとして任意採用です:

  • 役満の提案: 天和 / 地和（配牌での成立）
  • 食物一色: 全部食べ物・飲み物だけで構成
  • 疑似俳句: カン等で5・7・5、または面前14牌で文章化
  • しばりルール: 動物しばり / 食べ物しばり / 地名しばり / アニメキャラクターしばり
  • 点数倍率の変更（例: 9点）

ロン・ツモの点数、七対子、カンの補充枚数は公式商品ページに詳細が掲載されていないため、このアプリの任意ルールとして表示・実装しています。遊ぶ前に採用するか確認してください。
